## What's new

- **Rename tasks in place.** Double-click a task in All Tasks or in a project's task list to edit its title right there. Return or a click elsewhere saves, Tab saves and jumps to the next task (Shift-Tab to the previous one), Esc discards. The pencil on hover still opens all of the task's details.
- **New app icon.** An orange to pink bookmark with a wave, on a dark plate.

## Fixes

- Renaming a task that syncs to Apple Reminders now renames the reminder too.
